 Ambulance and Emergency Dispatch System

 1. Project Title
Ambulance and Emergency Dispatch System Using C++ and Data Structures

 2. Description
The Ambulance and Emergency Dispatch System is a C++-based project designed to improve the efficiency of emergency response. It prioritizes emergency requests according to their severity and assigns the nearest suitable available ambulance. The system uses data structures and algorithms to reduce dispatch delays and improve ambulance resource utilization.

 3. Features
•⁠  ⁠Emergency Request Management:* Accepts and records emergency requests.
•⁠  ⁠Priority-Based Dispatch:* Prioritizes emergencies according to their severity.
•⁠  ⁠Ambulance Management:* Maintains ambulance details and availability status.
•⁠  ⁠Ambulance Assignment:* Assigns a suitable available ambulance to an emergency.
•⁠  ⁠Shortest-Path Calculation:* Uses Dijkstra's algorithm to calculate the shortest route in a represented road network.
•⁠  ⁠Dispatch Records:* Maintains records of emergency requests and ambulance assignments.

 4. Technologies Used
•⁠  ⁠Programming Language:- C++
•⁠  ⁠Data Structures:- Max-Heap, Priority Queue, Graph
•⁠  ⁠Algorithms:* Dijkstra's Shortest Path Algorithm
•⁠  ⁠Concepts:* Object-Oriented Programming and Graph Traversal
•⁠  ⁠Development Tools:- Visual Studio Code and a C++ compiler (G++)

3.⁠ ⁠Clone or download this repository.
4.⁠ ⁠Open the project folder in your editor.

   ⁠ bash

    ⁠

   Windows:
   ⁠ bash

    ⁠

   ⁠ bash

    ⁠

 6. How to Use
1.⁠ ⁠Run the compiled program.
2.⁠ ⁠Select the required option from the menu.
3.⁠ ⁠Enter the emergency request details, including location and severity.
4.⁠ ⁠View the priority of the emergency request.
5.⁠ ⁠Allow the system to assign a suitable available ambulance.
